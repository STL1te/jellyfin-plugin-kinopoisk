По умолчанию используется общий ключ. Если плагин работает плохо или упирается в лимит запросов, зарегистрируйте свой на kinopoiskapiunofficial.tech и укажите его здесь. Изменение ключа применяется после перезапуска сервера.

Недостающие эпизоды

Создаёт заготовки для эпизодов, дата выхода которых ещё не наступила. Они попадают в раздел «Скоро». Увеличивает время сканирования библиотеки.
Создаёт заготовки для уже вышедших эпизодов, для которых нет файла — они отображаются как пропущенные. Увеличивает время сканирования библиотеки.
КиноПоиск складывает в нулевой сезон пилоты и разнородные дополнительные материалы, поэтому по умолчанию они не добавляются.
Если выключить оба варианта, ранее созданные заготовки будут удалены при следующем обновлении метаданных сериала.
