# jellyfin-plugin-kinopoisk

Плагин метаданных для Jellyfin, забирает информацию о фильмах и сериалах с [КиноПоиска](https://www.kinopoisk.ru/)
через [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech).

Форк [LinFor/jellyfin-plugin-kinopoisk](https://github.com/LinFor/jellyfin-plugin-kinopoisk).

## Установка

Администрирование - Панель - Расширенное - Плагины - вкладка Репозитории - добавить адрес
https://raw.githubusercontent.com/STL1te/jellyfin-plugin-kinopoisk/master/dist/manifest.json

После этого на вкладке Каталог найти "КиноПоиск" (раздел Метаданные) и установить.

Альтернатива для Emby - [luzmane/emby.kinopoisk.ru](https://github.com/luzmane/emby.kinopoisk.ru)

## Настройка

Параметры плагина искать в: Администрирование - Панель - Расширенное - Плагины - вкладка "Мои плагины" - КиноПоиск - "три точки" - Параметры

По умолчанию прописан общий ключ API - он без дневного лимита, но один на всех. Свой ключ можно зарегистрировать
на [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech); учтите, что бесплатный тариф там ограничен
500 запросами в сутки, и при обновлении большой библиотеки этого не хватит. Смена ключа применяется после
перезапуска сервера.

## Использование

Требуется Jellyfin 12.0 или новее. Сборки для 10.10/10.11 лежат в релизах до `10.10.3.0`.

Поддерживаются:
- Фильмы
- Сериалы (включая метаданные эпизодов)
- Персоны

На данный момент грузятся:
- Название, оригинальное название, описание, слоган
- Рейтинг КиноПоиска/IMDb и рейтинг критиков
- Год, дата премьеры и прокатчики (студии)
- Длительность, возрастной рейтинг, жанры, страны, ссылка на страницу КиноПоиска
- Для сериалов - статус (идёт/завершён), год окончания, даты сезонов, названия/описания/даты выхода эпизодов
- Постеры, фоны (обложка, фон-арт, обои) и логотип
- Актёры и съёмочная группа, их фото, даты жизни и факты биографии
- Трейлеры (только те, что лежат на ютубе - Jellyfin-Web не умеет играть трейлеры, лежащие на самом КиноПоиске)
- Похожие фильмы, сиквелы и приквелы - в блок рекомендаций Jellyfin
- Поиск по библиотеке через индекс КиноПоиска: фильм находится и по русскому, и по оригинальному названию

Плагин будет пытаться найти в имени файла (для фильмов) или имени корневой папки (для сериалов) паттерн вида "kp-12345" или "kp12345", где число - id фильма на сайте КиноПоиск.

### Анонсированные и пропущенные эпизоды

В параметрах плагина можно включить создание заготовок для эпизодов, которые есть у КиноПоиска, но которых нет
в библиотеке: анонсированных (попадают в раздел "Скоро") и уже вышедших, но без файла (показываются как пропущенные).
По умолчанию выключено, так как заметно удлиняет сканирование. Если выключить обратно - заготовки будут удалены
при следующем обновлении метаданных сериала.

Чтобы это работало, КиноПоиск должен быть включён как источник метаданных для эпизодов и сезонов:
Библиотека - "три точки" - Управление библиотекой - Источники метаданных.
